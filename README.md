# Farm3x3
Farm 3x3 is a data pack that harvests crops in a 3x3 square if you hold a hoe.  
The crops will also automatically replant if you hold a hoe in your offhand. (in Minecraft 1.21+, Farm3x3 2.2.0+)

## Mod compatibility
- Read [this wiki page](https://github.com/Raixu27/Farm3x3/wiki/Supported-Crops) to see a list of all supported vanilla and modded crops.
- Additional data packs may be required for mod support, see the wiki page for more information.

## Notes
- To configure or remove the data pack, run ``/function farm3x3:settings``.
- The data pack will not work in creative mode.
